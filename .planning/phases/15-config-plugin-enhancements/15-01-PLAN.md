These two plugins share a common pattern: iterate key/value pairs, filter by connection key pattern, parse URL for hostname+protocol, and emit `ConnectionInfo`.

### Task 1: Create `src/plugin/config/url_util.rs` and register it

**Files:** `src/plugin/config/url_util.rs`, `src/plugin/config/mod.rs`

**Action:**

Create `src/plugin/config/url_util.rs` with three public functions. Use `url::Url::parse()` (already in Cargo.toml) — do NOT hand-roll URL parsing with `split("://")`.

```rust
use url::Url;

/// Returns (protocol, hostname) for a URL-like value, or None if not URL-like.
/// Skips template variables (hostname contains '{').
pub fn parse_url_value(val: &str) -> Option<(String, String)> {
    let url = Url::parse(val).ok()?;
    let hostname = url.host_str()?.to_string();
    if hostname.is_empty() || hostname.contains('{') {
        return None;
    }
    let protocol = scheme_to_protocol(url.scheme());
    Some((protocol, hostname))
}

/// Map URL scheme to canonical protocol string.
/// Returns the scheme as-is for unknown schemes (free string, no enum per CLAUDE.md).
pub fn scheme_to_protocol(scheme: &str) -> String {
    match scheme {
        "postgres" | "postgresql" => "postgresql",
        "mysql" | "mariadb" => "mysql",
        "redis" | "rediss" => "redis",
        "amqp" | "amqps" => "amqp",
        "kafka" => "kafka",
        "mongodb" | "mongodb+srv" => "mongodb",
        "http" | "https" => "http",
        "grpc" | "grpcs" => "grpc",
        other => other,
    }
    .to_string()
}

/// Returns true if the env key matches a connection pattern.
/// Suffix patterns: *_URL, *_HOST, *_ENDPOINT, *_ADDR, *_DSN
/// Exact names: DATABASE_URL, REDIS_URL, AMQP_URL, KAFKA_BROKERS
pub fn is_connection_key(key: &str) -> bool {
    const SUFFIXES: &[&str] = &["_URL", "_HOST", "_ENDPOINT", "_ADDR", "_DSN"];
    const EXACT: &[&str] = &["DATABASE_URL", "REDIS_URL", "AMQP_URL", "KAFKA_BROKERS"];
    EXACT.contains(&key) || SUFFIXES.iter().any(|suf| key.ends_with(suf))
}
```

Add unit tests in the same file covering:
- `parse_url_value("postgres://db.host/mydb")` → `Some(("postgresql", "db.host"))`
- `parse_url_value("redis://cache.internal:6379")` → `Some(("redis", "cache.internal"))`
- `parse_url_value("https://{server}/v2")` → `None` (template variable)
- `parse_url_value("not-a-url")` → `None`
- `parse_url_value("")` → `None`
- `scheme_to_protocol("postgres")` → `"postgresql"`
- `scheme_to_protocol("amqps")` → `"amqp"`
- `scheme_to_protocol("ftp")` → `"ftp"` (unknown scheme passes through)
- `is_connection_key("DATABASE_URL")` → `true`
- `is_connection_key("KAFKA_BROKERS")` → `true`
- `is_connection_key("MY_SERVICE_HOST")` → `true`
- `is_connection_key("APP_NAME")` → `false`
- `is_connection_key("PORT")` → `false`

Register in `src/plugin/config/mod.rs` by adding:
```rust
pub mod url_util;
```
Place it near the top of the file (before openapi, after the boundary comment).

**Verify:** `cargo test -p arcanon-scanner url_util -- --nocapture` passes all tests.

**Done:** `url_util.rs` exists, all tests pass, `pub mod url_util;` is in `mod.rs`.

### Task 2: Enhance `src/plugin/config/env.rs` to emit connections (DQ-05)

**Files:** `src/plugin/config/env.rs`

**Action:**

Replace the marker-only `extract()` implementation with one that:
1. Reads `file.content` (the `Arc<str>` already loaded — do NOT call `std::fs::read_to_string()`)
2. Parses .env format inline (copy the logic from `vars/mod.rs::parse_env_file()` — strip comments, blanks, `export ` prefix, strip surrounding quotes, split on first `=`)

### Task 3: Enhance `src/plugin/config/compose.rs` for environment: block extraction (DQ-06)

**Files:** `src/plugin/config/compose.rs`

**Action:**

Extend `ComposeService` to include an `environment` field using a new `ComposeEnv` untagged enum (same pattern as existing `DependsOn`). Then iterate per-service to emit `ConnectionInfo` for URL-valued keys.

1. Add `ComposeEnv` enum and update `ComposeService`:

```rust
use std::collections::HashMap;

#[derive(Deserialize, Default)]
#[serde(untagged)]
enum ComposeEnv {
    #[default]
    None,
    List(Vec<String>),                               // ["KEY=value"]
    Map(HashMap<String, serde_yaml_bw::Value>),      // {KEY: value}
}

#[derive(Deserialize, Default)]
struct ComposeService {
    #[serde(default)]
    depends_on: DependsOn,
    #[serde(default)]
    environment: ComposeEnv,
}
```

2. Add imports at the top:
```rust
use super::url_util::{is_connection_key, parse_url_value};
use crate::types::{ConnectionInfo};  // Confidence already imported
```

3. In the `extract()` method, after the existing `depends_on` connection loop, add an env extraction loop. Iterate over `compose.services` by `(service_name, service)`. For `ComposeEnv::List(seq)`, split each `"KEY=val"` item on the first `=`. For `ComposeEnv::Map(m)`, get each value as a string via `.as_str()` or `.to_string()` on the `serde_yaml_bw::Value`.

For each key/value pair:
- Check `is_connection_key(key)` → skip if false
- Call `parse_url_value(val)` → if `Some((protocol, hostname))` → push `ConnectionInfo`:

  - `extraction_method`: `"compose"`
  - `dependency`: `None`
  - `evidence`: `Some(format!("{}={}", key, val))`

Note: The map form's value may be `serde_yaml_bw::Value::String(s)` or other variants. Extract string with `v.as_str().map(|s| s.to_string()).or_else(|| Some(v.to_string()))` — but skip non-string values (numbers, booleans are not URLs).

## Threat Model

| Boundary | Description |
|----------|-------------|
| .env file content → ConnectionInfo | Untrusted file content parsed for URLs |
| Compose YAML → ConnectionInfo | Untrusted YAML values parsed for URLs |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01 | Information Disclosure | url_util::parse_url_value | accept | Parsing is read-only; extracted hostnames go into scan payload, not executed; no PII risk |
| T-15-02 | Denial of Service | env.rs parse loop | accept | Files are pre-loaded by scanner; no filesystem access in plugin; loop complexity is O(lines) — bounded by file size which the scanner already limits |
| T-15-03 | Spoofing | Compose env map values | accept | Values are string-parsed, not executed; false positives are logged as evidence for human review |
