<objective>
Implement the git context detection module that produces repo metadata before any plugin runs.

Purpose: Every `ScanPayloadV1` upload carries repo_url, branch, and commit_sha. These three values identify the scan to the hub and act as the idempotency key. Wrong values mean the hub cannot reconcile scans across CI runs. The fallback chain exists because CI systems always check out in detached HEAD mode — without the env-var fallbacks, every CI scan reports branch="detached".

Output: `src/git/mod.rs` exporting `GitContext` struct and `detect_git_context(root) -> anyhow::Result<GitContext>`, plus tests covering the fallback chain and repo_name derivation.
</objective>

```rust
pub struct GitContext {
    /// Remote URL (None if not a git repo or no remotes)
    pub repo_url: Option<String>,
    /// Repo name derived from URL basename or directory name
    pub repo_name: String,
    /// Branch name with full fallback chain
    pub branch: String,
    /// 40-char hex commit SHA with full fallback chain
    pub commit_sha: String,
}
```

Confirmed gix API (from RESEARCH.md — verified against docs.rs/gix/0.81.0):
```rust
use gix::remote::Direction;

// Discover: walks up from root until .git is found
let repo = gix::discover(root)?;                        // returns Err if not a git repo

// Commit SHA
let sha = repo.head_id()?.to_hex().to_string();         // 40-char hex

// Branch (None if detached HEAD)
let branch = repo.head()?
    .referent_name()                                     // None when detached
    .map(|name| name.shorten().to_string());             // "main" not "refs/heads/main"

// Remote URL (origin preferred, then first available)
let url = repo
    .try_find_remote("origin")
    .transpose()?
    .flatten()
    .and_then(|remote| remote.url(Direction::Fetch).cloned())
    .map(|url| format!("{url}"));                        // Display impl — safe for UTF-8 URLs
```

Cargo.toml addition:
```toml
gix = { version = "0.81", default-features = false, features = ["rev-parse-delegate"] }
```

Key pitfalls (from RESEARCH.md Pitfall 1 and 3 and 6):
- In CI, HEAD is always detached — `referent_name()` returns `None`. MUST use env var fallback.
- Fallback chain order: ARCANON_BRANCH → GITHUB_REF_NAME → CI_COMMIT_BRANCH → BRANCH_NAME → "detached"
- For commit SHA: ARCANON_COMMIT_SHA → GITHUB_SHA → CI_COMMIT_SHA → content_hash_fallback()
- Use `format!("{url}")` (Display impl) not `.to_string()` directly on gix_url::Url
- `repo.remote_names()` returns BString — use `.as_ref()` to get &BStr when passing to `try_find_remote`

Content hash fallback (for commit_sha when no git and no CI env var):
- Compute SHA-256 of the concatenated string: for each file in sorted(relative_path:file_size_bytes), join with newline
- Do NOT include modification time (not deterministic across CI runs)
- Return as hex string
- Add `sha2 = "0.10"` to Cargo.toml for SHA-256

CI env var reference table (verified against official docs):
| Field  | GitHub Actions    | GitLab CI         | Jenkins (multibranch) | Override |
|--------|-------------------|-------------------|-----------------------|----------|
| Branch | GITHUB_REF_NAME   | CI_COMMIT_BRANCH  | BRANCH_NAME           | ARCANON_BRANCH |
| SHA    | GITHUB_SHA        | CI_COMMIT_SHA     | GIT_COMMIT            | ARCANON_COMMIT_SHA |

Implement `pub struct GitContext` with fields: `repo_url: Option<String>`, `repo_name: String`, `branch: String`, `commit_sha: String`.

Implement `pub fn detect_git_context(root: &std::path::Path) -> anyhow::Result<GitContext>`:
- Call `gix::discover(root).ok()` (use `.ok()` — not a git repo is not an error at this level)
- Call private `detect_remote(repo.as_ref(), root)` → `(Option<String>, String)` for (repo_url, repo_name)
- Call private `detect_branch(repo.as_ref())` → `String`
- Call private `detect_commit_sha(repo.as_ref(), root)` → `String`
- Return `Ok(GitContext { repo_url, repo_name, branch, commit_sha })`

Implement `fn detect_remote(repo: Option<&gix::Repository>, root: &std::path::Path) -> (Option<String>, String)`:
- Try `repo.and_then(|r| r.try_find_remote("origin").transpose().ok().flatten())`
- If no "origin", try first remote: `r.remote_names().into_iter().next()` then `r.try_find_remote(name.as_ref()).transpose().ok().flatten()`
- Get URL: `.and_then(|remote| remote.url(Direction::Fetch).cloned()).map(|url| format!("{url}"))`
- Derive repo_name: split url_str on '/', take last segment, strip ".git" suffix
- Fallback repo_name: `root.file_name().and_then(|n| n.to_str()).unwrap_or("unknown").to_string()`
- Return `(url_str, repo_name)`

Implement `fn detect_branch(repo: Option<&gix::Repository>) -> String`:
- If repo is Some: try `repo.head().ok()` → `.referent_name()` → `.map(|n| n.shorten().to_string())`
- If Some(branch_string) and non-empty, return it immediately
- Fallback chain (in order):
  1. `std::env::var("ARCANON_BRANCH")`
  2. `std::env::var("GITHUB_REF_NAME")`
  3. `std::env::var("CI_COMMIT_BRANCH")`
  4. `std::env::var("BRANCH_NAME")`
- For each: if Ok(val) and val is not empty, return val
- Final fallback: emit `tracing::warn!("Could not detect branch name; using 'detached'. Set ARCANON_BRANCH or GITHUB_REF_NAME.")` and return `"detached".to_string()`

Implement `fn detect_commit_sha(repo: Option<&gix::Repository>, root: &std::path::Path) -> String`:
- If repo is Some: try `repo.head_id().ok().map(|id| id.to_hex().to_string())`
- If Some(sha) and non-empty, return it immediately
- Fallback chain (in order):
  1. `std::env::var("ARCANON_COMMIT_SHA")`
  2. `std::env::var("GITHUB_SHA")`
  3. `std::env::var("CI_COMMIT_SHA")`
  4. `std::env::var("GIT_COMMIT")`
- For each: if Ok(val) and val is not empty, return val
- Final fallback: emit `tracing::warn!("Could not detect commit SHA; using content hash fallback.")` then call `content_hash_fallback(root)`

Implement `fn content_hash_fallback(root: &std::path::Path) -> String`:
- Walk the root directory using `std::fs::read_dir` recursively, collecting relative file paths
- For each file: get its size via `metadata().len()`
- Sort entries by relative path string
- Build a string: each entry is `"{relative_path}:{size}\n"`, concatenated
- Compute SHA-256 of that string using `sha2::Sha256`
- Return lowercase hex string of the 32-byte digest
- Use `sha2::Digest` trait: `use sha2::{Digest, Sha256}; let mut hasher = Sha256::new(); hasher.update(content.as_bytes()); format!("{:x}", hasher.finalize())`

```rust
use arcanon_scanner::git::detect_git_context;

#[test]
fn test_non_git_dir() {
    let dir = tempfile::tempdir().unwrap();
    // Ensure no CI env vars interfere
    std::env::remove_var("ARCANON_BRANCH");
    std::env::remove_var("GITHUB_REF_NAME");
    std::env::remove_var("CI_COMMIT_BRANCH");
    std::env::remove_var("BRANCH_NAME");
    std::env::remove_var("ARCANON_COMMIT_SHA");
    std::env::remove_var("GITHUB_SHA");
    std::env::remove_var("CI_COMMIT_SHA");
    std::env::remove_var("GIT_COMMIT");

    let ctx = detect_git_context(dir.path()).unwrap();
    assert!(ctx.repo_url.is_none(), "non-git dir should have no repo_url");
    assert_eq!(ctx.branch, "detached", "non-git dir with no CI env should use 'detached'");
    // repo_name should be the directory basename (temp dirs have a name)
    assert!(!ctx.repo_name.is_empty(), "repo_name should fall back to dir name");
    // commit_sha should be a non-empty deterministic hash
    assert!(!ctx.commit_sha.is_empty(), "commit_sha should be content hash fallback");
    assert_eq!(ctx.commit_sha.len(), 64, "SHA-256 hex should be 64 chars");
}

#[test]
fn test_repo_name_derivation() {
    // Test the URL parsing logic for repo_name
    // We test this by checking that detect_git_context on a dir with no git
    // uses the dir name as fallback
    let dir = tempfile::TempDir::new_in("/tmp").unwrap();
    // The dir has a system-assigned name — just verify it's non-empty
    let ctx = detect_git_context(dir.path()).unwrap();
    assert!(!ctx.repo_name.is_empty());
}

#[test]
fn test_branch_ci_env_fallback() {
    let dir = tempfile::tempdir().unwrap();
    // Clear gix-detectable context and set CI env var
    std::env::remove_var("ARCANON_BRANCH");
    std::env::set_var("GITHUB_REF_NAME", "feature/test-branch");
    std::env::remove_var("CI_COMMIT_BRANCH");
    std::env::remove_var("BRANCH_NAME");

    let ctx = detect_git_context(dir.path()).unwrap();
    // Non-git dir won't have a branch from gix, so GITHUB_REF_NAME should be used
    assert_eq!(ctx.branch, "feature/test-branch",
        "should use GITHUB_REF_NAME when gix cannot detect branch");

    // Cleanup
    std::env::remove_var("GITHUB_REF_NAME");
}

#[test]
fn test_arcanon_branch_overrides_github_ref() {
    let dir = tempfile::tempdir().unwrap();
    std::env::set_var("ARCANON_BRANCH", "arcanon-override");
    std::env::set_var("GITHUB_REF_NAME", "github-branch");

    let ctx = detect_git_context(dir.path()).unwrap();
    assert_eq!(ctx.branch, "arcanon-override",
        "ARCANON_BRANCH should have higher priority than GITHUB_REF_NAME");

    std::env::remove_var("ARCANON_BRANCH");
    std::env::remove_var("GITHUB_REF_NAME");
}

#[test]
fn test_content_hash_is_deterministic() {
    // Two dirs with identical content should produce the same hash
    let dir1 = tempfile::tempdir().unwrap();
    let dir2 = tempfile::tempdir().unwrap();

    for dir in &[&dir1, &dir2] {
        std::fs::create_dir_all(dir.path().join("src")).unwrap();
        std::fs::write(dir.path().join("src/main.rs"), b"fn main() {}").unwrap();
        std::fs::write(dir.path().join("Cargo.toml"), b"[package]\nname = \"test\"").unwrap();
    }

    std::env::remove_var("ARCANON_BRANCH");
    std::env::remove_var("GITHUB_REF_NAME");
    std::env::remove_var("CI_COMMIT_BRANCH");
    std::env::remove_var("BRANCH_NAME");
    std::env::remove_var("ARCANON_COMMIT_SHA");
    std::env::remove_var("GITHUB_SHA");
    std::env::remove_var("CI_COMMIT_SHA");
    std::env::remove_var("GIT_COMMIT");

    let ctx1 = detect_git_context(dir1.path()).unwrap();
    let ctx2 = detect_git_context(dir2.path()).unwrap();

    // Content is identical so hashes must match
    assert_eq!(ctx1.commit_sha, ctx2.commit_sha,
        "same content in different dirs should produce identical content hash");
}

#[test]
fn test_content_hash_is_64_hex_chars() {
    let dir = tempfile::tempdir().unwrap();
    std::fs::write(dir.path().join("file.txt"), b"some content").unwrap();

    std::env::remove_var("ARCANON_COMMIT_SHA");
    std::env::remove_var("GITHUB_SHA");
    std::env::remove_var("CI_COMMIT_SHA");
    std::env::remove_var("GIT_COMMIT");

    let ctx = detect_git_context(dir.path()).unwrap();
    // SHA-256 produces 32 bytes = 64 hex chars
    assert_eq!(ctx.commit_sha.len(), 64, "content hash fallback should be 64 hex chars (SHA-256)");
    assert!(ctx.commit_sha.chars().all(|c| c.is_ascii_hexdigit()),
        "commit_sha should be all hex characters");
}
```
