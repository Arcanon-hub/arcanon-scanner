    - Test 2: two separate services both importing the same library produce 2 connections (one per service), not N×import_lines
    - Test 3: a library with two protocols (e.g., redis over redis+tls) produces 2 connections per service
  </behavior>
  <action>
    Replace the per-import-line emission with deduplication. The fix: collect the first import-line evidence per (lib_name, protocol, source_service) triple, then emit exactly one ConnectionInfo per unique triple.

    Concrete implementation in the block starting at line 253:

    1. Add `use std::collections::HashSet;` if not already imported (it is imported — check existing imports).
    2. Replace the four-level nested loop with a two-level loop (resolved → protocols) that:
       a. Determines source_service by scanning lang_files for the first file that imports the library (use `line_contains_import`), using `scope_to_service` on that file.
       b. If no import line found in any file, skip (same logic as before — no source_service).
       c. Use a `HashSet<(String, String, String)>` keyed on `(lib_name.clone(), protocol.clone(), source_service.clone())` to deduplicate before pushing to `libres_connections`.
       d. For evidence, capture the first matching import line text.
       e. For source_file, use `format!("{}", first_matching_file.relative_path)` — drop the line number since we're no longer line-level.

    The resulting emission: for each (resolved_lib, protocol), scan all lang_files for any import of the lib. Group by source_service. Emit one ConnectionInfo per unique (lib, protocol, service) with the first found import line as evidence.

    Exact structure:
    ```
    let mut seen: HashSet<(String, String, String)> = HashSet::new();
    for resolved in &resolved_libs {
        for protocol in &resolved.protocols {
            for file in &lang_files {
                // find first import line for this lib in this file
                let first_import = file.content.lines().enumerate()
                    .find(|(_, line)| line_contains_import(line.trim(), &resolved.lib_name));
                if let Some((line_no, evidence_line)) = first_import {
                    let source_service = crate::plugin::scope_to_service(&file.path, &service_roots)
                        .unwrap_or("").to_string();
                    let key = (resolved.lib_name.clone(), protocol.clone(), source_service.clone());
                    if seen.insert(key) {
                        libres_connections.push(ConnectionInfo { ... source_file: file.relative_path.clone(), evidence: Some(evidence_line.trim().to_string()), ... });
                    }
                }
            }
        }
    }
    ```

    The `seen.insert(key)` returns true only on first insertion — subsequent files in the same service that import the same lib are skipped.

    Do NOT change anything outside the block delimited by the `if !resolved_libs.is_empty() {` / closing `}` on line ~305.
