<objective>
Fix wrapper tracing false positive amplification by (1) reducing the chain depth cap from 5 to 2, (2) adding a blocklist of generic function names that must never be treated as wrappers, and (3) covering both changes with regression tests.

Purpose: The current depth-5 cap allows transitive call graphs to explode from 6 seeds to 57 wrappers (231 traced connections in Pass 2 for opcua-adapter, mostly false). Limiting depth to 2 and blocking generic lifecycle names eliminates the amplification while preserving real 1-hop and 2-hop wrapper detection.

Output: Modified `src/wrapper/mod.rs` with updated depth constants, blocklist constant, and eight regression tests.
</objective>
