Implement `PatternRegistry::load(hub_url: Option<&str>) -> Self` as an **async** function:

```
1. Determine cache path: dirs::home_dir()?.join(".arcanon/patterns.json")
   Use std::env::var("HOME") as fallback if dirs crate is not available.
   Actually: use std::env::var("HOME").ok().map(|h| PathBuf::from(h).join(".arcanon/patterns.json"))
   to avoid adding new dependencies (dirs crate not in Cargo.toml).

2. Read cached ETag if it exists: cache_path with ".etag" suffix
   e.g. ~/.arcanon/patterns.json.etag

3. Build reqwest::Client, GET "https://patterns.arcanon.dev/v1/patterns.json"
   - Set header: If-None-Match: {etag} if etag is present
   - Set header: Accept: application/json
   - Timeout: 10 seconds

4. On HTTP 200: parse body as PatternFile, write JSON to cache_path,
   write ETag response header to cache_path.etag if present.
   Return PatternRegistry { patterns, version, source: PatternSource::Remote }

5. On HTTP 304: read cache_path, parse PatternFile from it.
   Return PatternRegistry { ..., source: PatternSource::Cache }

6. On any error (network, timeout, parse, non-200/304):
   tracing::warn!("Pattern fetch failed: {e}. Falling back to cache.");
   Try reading cache_path. If successful, parse and return PatternSource::Cache.
   If cache also fails:
   tracing::warn!("No pattern cache found. Running with zero dynamic patterns.");
   Return PatternRegistry { patterns: vec![], version: "".to_string(), source: PatternSource::None }
```

IMPORTANT: This function is async. It will be called from scanner::run() which runs in a tokio runtime context (see scanner wiring in Plan 04). Do NOT use reqwest::blocking — use async reqwest.

Cache directory creation: `std::fs::create_dir_all(cache_path.parent()?)` before writing.

Add `impl PatternRegistry { pub fn apply(&self, file: &FileContext, language: &str, service_roots: &HashMap<PathBuf, String>) -> Vec<ConnectionInfo> }` to `src/patterns/mod.rs`.

Algorithm (per D-07, no regex):

```
for each pattern in self.patterns:
  if pattern.languages does not contain language → skip
  if import_gate is non-empty AND none of import_gate strings appear in file.content → skip
  for each (line_number, line) in file.content.lines().enumerate():
    for each detection in pattern.detections:
      if line does not contain detection.match_str → continue
      let target = extract_target(line, &detection.target_extraction)
      let (target_name, confidence) = match target:
        Some(t) if !t.is_empty() => (t, map_confidence(&detection.confidence))
        _ => ("".to_string(), Confidence::Medium)  // D-09
      push ConnectionInfo {
        source_service: scope_to_service(file.path, service_roots)
                          .unwrap_or("").to_string(),
        target_name,
        protocol: detection.protocol.clone(),
        method: None,
        path: None,
        source_file: format!("{}:{}", file.relative_path, line_number + 1),
        confidence,
        extraction_method: format!("pattern:{}", pattern.id),
        evidence: Some(line.trim().to_string()),
      }
return findings
```

Target extraction helpers (D-07: simple string ops only, no regex):

```rust
fn extract_target(line: &str, strategy: &TargetExtraction) -> Option<String> {
    match strategy {
        TargetExtraction::None => None,
        TargetExtraction::FirstStringArg => {
            // Find first " or ' after the match, then find closing quote
            extract_first_string(line)
        }
        TargetExtraction::NamedArg(key) => {
            // Find "KEY=" then extract quoted value
            let needle = format!("{}=", key);
            extract_named_arg(line, &needle)
        }
        TargetExtraction::UrlHostname => {
            // Extract first string, then parse as URL and get host
            extract_first_string(line).and_then(|url| {
                // Simple: find "://" then take until next "/"
                url.find("://").map(|i| {
                    let after = &url[i+3..];
                    after.split('/').next().unwrap_or("").to_string()
                })
            })
        }
    }
}

fn extract_first_string(line: &str) -> Option<String> {
    // Find first " or ' in the line
    let bytes = line.as_bytes();
    for (i, &b) in bytes.iter().enumerate() {
        if b == b'"' || b == b'\'' {
            let quote = b as char;
            let rest = &line[i+1..];
            if let Some(end) = rest.find(quote) {
                return Some(rest[..end].to_string());
            }
        }
    }
    None
}
```

Note: `None` returned from extract_target when no strategy applies or extraction fails → per D-09, emit target_name="" confidence=Medium.
