<!-- From RESEARCH.md Pattern 5: Upload with Retry -->
Retry logic:
- MAX_RETRIES = 3
- Attempt 0: immediate
- Attempt 1: sleep 1s (1 << 0)
- Attempt 2: sleep 2s (1 << 1)
- Attempt 3: sleep 4s (1 << 2)
- Retry on: HTTP 429, 500-599
- Do NOT retry on: 400, 401, 409, 413 (return immediately)
- Network error on final attempt: save to file

<!-- FTOL-02 Pattern from RESEARCH.md Pattern 2 -->
Plugin panic capture pattern (for scanner.rs Plan 05, but documented here):
```rust
use std::panic::{self, AssertUnwindSafe};
match panic::catch_unwind(AssertUnwindSafe(|| plugin.extract(&ctx))) {
    Ok(result) => Some(result),
    Err(panic_val) => {
        let msg = panic_val.downcast_ref::<&str>().copied().unwrap_or("unknown panic");
        error!("plugin '{}' panicked: {}", plugin.name(), msg);
        None
    }
}

    pub async fn upload(payload: &ScanPayloadV1, config: &UploadConfig) -> anyhow::Result<()>:

    1. Serialize: body = serde_json::to_string(payload)?
    2. Build reqwest::Client::new()
    3. Retry loop for attempt in 0..=3:
       - if attempt > 0: tokio::time::sleep(Duration::from_secs(1_u64 << (attempt - 1))).await
       - POST to format!("{}/api/v1/scans/upload", config.hub_url)
         with header "Authorization" = format!("Bearer {}", config.api_key)
         with header "Content-Type" = "application/json"
         with body = body.clone()
       - On reqwest::Error (network failure):
         * If attempt == 3: call save_payload_to_file(payload) and return Err(...)
         * Else: warn!("Upload attempt {} failed: {}", attempt + 1, e); continue
       - On Ok(response): match response.status().as_u16():
         * 202 → info!("Upload accepted"); return Ok(())
         * 409 → info!("Duplicate scan (commit already processed)"); return Ok(())  // exit 0
         * 429 | 500..=599 → warn!("Retryable response {}", status); continue retry loop
         * 400 → anyhow::bail!("Payload validation failed: {}", response.text().await?)
         * 401 → anyhow::bail!("Authentication failed — check ARCANON_API_KEY")
         * 413 → anyhow::bail!("Payload too large")
         * other → anyhow::bail!("Unexpected response: {}", status)
    4. After loop ends without returning: return Err(anyhow!("Upload failed after 3 retries"))

    fn save_payload_to_file(payload: &ScanPayloadV1) -> anyhow::Result<()>:
    - timestamp = std::time::SystemTime::now().duration_since(UNIX_EPOCH)?.as_secs()
    - filename = format!("arcanon-scan-{}.json", timestamp)
    - json = serde_json::to_string_pretty(payload)?
    - std::fs::write(&filename, json)?
    - warn!("Network unreachable. Payload saved to {}", filename)
    - return Err(anyhow!("Upload failed: network unreachable. Payload saved to {}", filename))

       use anyhow::anyhow;
       use std::time::{Duration, UNIX_EPOCH};
       use tracing::{info, warn, error};
       use crate::core::payload::ScanPayloadV1;

       pub struct UploadConfig {
           pub hub_url: String,
           pub api_key: String,
       }

       pub async fn upload(payload: &ScanPayloadV1, config: &UploadConfig) -> anyhow::Result<()> {
           let body = serde_json::to_string(payload)
               .map_err(|e| anyhow!("Failed to serialize payload: {}", e))?;
           let client = reqwest::Client::new();
           let url = format!("{}/api/v1/scans/upload", config.hub_url);

           for attempt in 0u32..=3 {
               if attempt > 0 {
                   tokio::time::sleep(Duration::from_secs(1_u64 << (attempt - 1))).await;
               }
               match client
                   .post(&url)
                   .header("Authorization", format!("Bearer {}", config.api_key))
                   .header("Content-Type", "application/json")
                   .body(body.clone())
                   .send()
                   .await
               {
                   Err(e) => {
                       warn!("Upload attempt {} failed: {}", attempt + 1, e);
                       if attempt == 3 {
                           save_payload_to_file(payload)?;
                           return Err(anyhow!("Upload failed after 3 retries: {}", e));
                       }
                   }
                   Ok(response) => match response.status().as_u16() {
                       202 => { info!("Upload accepted (202)"); return Ok(()); }
                       409 => { info!("Duplicate scan (409) — commit already processed"); return Ok(()); }
                       429 | 500..=599 => { warn!("Retryable response {} on attempt {}", response.status(), attempt + 1); }
                       400 => { return Err(anyhow!("Payload validation failed (400): {}", response.text().await.unwrap_or_default())); }
                       401 => { return Err(anyhow!("Authentication failed (401) — check ARCANON_API_KEY")); }
                       413 => { return Err(anyhow!("Payload too large (413)")); }
                       code => { return Err(anyhow!("Unexpected response: {}", code)); }
                   }
               }
           }
           Err(anyhow!("Upload failed after 3 retries"))
       }

       fn save_payload_to_file(payload: &ScanPayloadV1) -> anyhow::Result<()> {
           let secs = std::time::SystemTime::now()
               .duration_since(UNIX_EPOCH)
               .map(|d| d.as_secs())
               .unwrap_or(0);
           let filename = format!("arcanon-scan-{}.json", secs);
           let json = serde_json::to_string_pretty(payload)?;
           std::fs::write(&filename, &json)?;
           warn!("Network unreachable — payload saved to {}", filename);
           Ok(())
       }
       ```
