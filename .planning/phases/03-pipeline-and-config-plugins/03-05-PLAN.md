    run_plugins_parallel helper:
    ```rust
    fn run_plugins_parallel(
        plugins: &[Box<dyn LanguagePlugin>],
        all_files: &[FileContext],
        vars: &Arc<VariableStore>,
        root: &Path,
    ) -> Vec<ExtractionResult> {
        plugins.par_iter().filter_map(|plugin| {
            let matching: Vec<FileContext> = if plugin.always_run() {
                filter_files_by_patterns(all_files, plugin.file_patterns())
            } else {
                let matched = filter_files_by_patterns(all_files, plugin.file_patterns());
                if matched.is_empty() { return None; }
                matched
            };
            let ctx = ExtractionContext {
                files: matching,
                vars: Arc::clone(vars),
                root: root.to_path_buf(),
            };
            match std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| plugin.extract(&ctx))) {
                Ok(result) => Some(result),
                Err(panic_val) => {
                    let msg = panic_val.downcast_ref::<&str>().copied().unwrap_or("unknown panic");
                    tracing::error!("plugin '{}' panicked: {}", plugin.name(), msg);
                    None
                }
            }
        }).collect()
    }
    ```

    filter_files_by_patterns: use globset to match file paths. Plugin file_patterns() are glob patterns — compile them into a GlobSet and match against each file's relative_path.

    Note: always_run() = true means the plugin gets an empty files list if no files match (and should return an empty ExtractionResult gracefully). Actually, for always_run() = true plugins, pass ALL matching files (even if empty — the plugin decides what to do). For always_run() = false plugins, skip the plugin entirely if no files match (optimization).

    Timestamp format: use `std::time::SystemTime::now()` + format as RFC3339 manually, or use `chrono` if it's already a dependency. If chrono is NOT in Cargo.toml, use:

    ```rust
    fn now_rfc3339() -> String {
        let secs = std::time::SystemTime::now()
            .duration_since(std::time::UNIX_EPOCH)
            .unwrap_or_default()
            .as_secs();
        // Simple approximation — not perfectly RFC3339 but adequate for v1
        // Better: add chrono to Cargo.toml
        format!("{}", secs)
    }
    ```
    If chrono is not already a dep, add `chrono = { version = "0.4", features = ["serde"] }` to Cargo.toml.
    Then use: `chrono::Utc::now().to_rfc3339()`

       ```rust
       fn filter_files_by_patterns(files: &[FileContext], patterns: &[&str]) -> Vec<FileContext> {
           let mut builder = globset::GlobSetBuilder::new();
           for pattern in patterns {
               if let Ok(glob) = globset::Glob::new(pattern) {
                   builder.add(glob);
               }
           }
           let globset = builder.build().unwrap_or_else(|_| globset::GlobSet::empty());
           files.iter()
               .filter(|f| globset.is_match(&f.relative_path))
               .cloned()
               .collect()
       }
       ```
