    Query src (Python grammar):
    ```scheme
    (decorated_definition
      (decorator
        (call
          function: (attribute
            object: (identifier) @obj
    ```

    Filter: @http_method in ["get","post","put","delete","patch"]
    EndpointInfo: method=@http_method.to_uppercase(), path=@path, handler=@handler, kind="rest", confidence=High

    Django urlpatterns:
    Query:
    ```scheme
    (assignment
      left: (identifier) @var_name
      right: (list
        (call
          function: (identifier) @path_fn
          arguments: (argument_list
            (string) @route
            (_) @view))))
    ```
    Filter: @var_name == "urlpatterns", @path_fn in ["path","re_path","url"]
    EndpointInfo: method="GET" (Django urlpatterns don't specify method — emit GET as placeholder), path=@route, confidence=Medium
