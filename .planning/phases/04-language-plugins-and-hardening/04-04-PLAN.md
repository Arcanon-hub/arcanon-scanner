<interfaces>
Go grammar node types (CRITICAL — differ from TypeScript and Python):
- call_expression (same name as TypeScript — good)
- selector_expression: has fields operand: and field: (not object: like TS member_expression)
- field_identifier: property name in selector_expression (not property_identifier)
- interpreted_string_literal: Go string literal (NOT "string" — critical difference, Pitfall 3)
- argument_list: (not arguments)
- identifier

    Framework marker check (LPLU-08):
    - Scan ctx.files for files named "go.mod"
    - gin: content.contains("github.com/gin-gonic/gin")
    - echo: content.contains("github.com/labstack/echo")
    - fiber: content.contains("github.com/gofiber/fiber")
    - http (stdlib): always true if any .go files exist (net/http is stdlib — no go.mod entry)

    Gin/Echo/Fiber route detection:
    Query (Go grammar):
    ```scheme
    (call_expression
      function: (selector_expression
        operand: (identifier) @router
        field: (field_identifier) @method)
      arguments: (argument_list
        (interpreted_string_literal) @path
        (_)+ @handlers))
    ```
    Filter: @method in ["GET","POST","PUT","DELETE","PATCH","HEAD","OPTIONS","Any","Handle","Use"]
    Note: Go uses capitalized HTTP verbs (GET not get) for Gin/Echo — filter accordingly
    EndpointInfo: method=@method (already uppercase), path=@path, kind="rest", confidence=High

    net/http HandleFunc detection:
    Query:
    ```scheme
    (call_expression
      function: (selector_expression
        operand: (identifier) @pkg
        field: (field_identifier) @fn)
      arguments: (argument_list
        (interpreted_string_literal) @path
        (_) @handler))
    ```
    Filter: @pkg in ["http","mux","r","router","mux"], @fn in ["HandleFunc","Handle"]
    EndpointInfo: method="GET" (HandleFunc doesn't specify method — use GET placeholder, Medium confidence)
    Actually: set method="" and kind="rest" with confidence=Medium since HandleFunc handles any method

    Tests (inline fixtures):
    - `r.GET("/users", getUsers)` → EndpointInfo GET /users High
    - `http.HandleFunc("/health", healthCheck)` → EndpointInfo path=/health confidence=Medium
    - go.mod with no framework entries → no Gin routes detected (net/http still works)

    CRITICAL: Use interpreted_string_literal in queries (not string) — Go strings are this node type.
  </behavior>

    4. impl LanguagePlugin:
