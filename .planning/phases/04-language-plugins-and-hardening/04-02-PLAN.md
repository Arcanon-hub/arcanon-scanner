  <behavior>
    Framework marker detection (LPLU-08):
    - Scan ctx.files for files ending "package.json"
    - If no package.json found: FrameworkSet { express: false, nestjs: false, nextjs: false, fastify: false }
    - Read package.json content (already in file.content — no extra I/O)
    - express: content.contains("\"express\"")
    - nestjs: content.contains("\"@nestjs/core\"")
    - nextjs: content.contains("\"next\"")
    - fastify: content.contains("\"fastify\"")

    Express route detection (when frameworks.express is true):
    - Query: (call_expression function: (member_expression object: (identifier) @receiver property: (property_identifier) @method) arguments: (arguments (string) @path (_)* @handler))
    - Filter: @method in ["get","post","put","delete","patch","head","options","all"]
    - @receiver allowed values: ["app","router","api","r","v1","v2"] — filter post-query
    - EndpointInfo: method=@method.to_uppercase(), path=@path, handler=@handler text, kind="rest", confidence=High, extraction_method="ast_express"

    NestJS two-phase extraction (when frameworks.nestjs is true, per DETQ-05):
    Phase A — collect class→prefix map per file:
    Query: (class_declaration (decorator (call_expression function: (identifier) @dec_name arguments: (arguments (string) @prefix))) name: (type_identifier) @class_name)
    Filter: @dec_name == "Controller"

    Phase B — collect method decorators with their enclosing class:
    Query: (method_definition (decorator (call_expression function: (identifier) @http_dec arguments: (arguments (string)? @method_path))) name: (property_identifier) @handler_name)
    Filter: @http_dec in ["Get","Post","Put","Delete","Patch"]

    Join: walk AST parent chain of method_definition node to find its class_declaration name,
    look up in Phase A map, prepend prefix to method_path.
    Full path = prefix + (method_path or "").
    If no matching class found in map, use method_path alone.

    - Write tests using inline fixture strings (not filesystem), per Pitfall 9.
    - Fixture for Express: `const app = express(); app.get('/users', getUsers);`
      Expect: endpoints contains EndpointInfo { method: "GET", path: "/users" }
    - Fixture for NestJS:
      `@Controller('/users') class UsersController { @Get('/:id') getUser() {} }`
      Expect: endpoints contains EndpointInfo { method: "GET", path: "/users/:id" }
  </behavior>

    source_file format: format!("{}:{}", file.relative_path, line)

    - got.get("url") → same
    - confidence: High if URL is string literal, Medium if variable

    Message queue (LPLU-09):
    - kafkajs: producer.send({ topic: "orders", ... }) → protocol="kafka", path="orders"
    - amqplib: channel.publish(exchange, routingKey, ...) → protocol="amqp", path=routingKey
    - mqtt.js: client.publish("topic", payload) → protocol="mqtt", path=topic

    Database clients (LPLU-10):
    - new Pool(config) from 'pg' import → protocol="postgresql"
    - mongoose.connect(uri) → protocol="mongodb"
    - new Redis(url) / redis.createClient(url) → protocol="redis"
    - mysql.createConnection(config) → protocol="mysql"
    - Detection strategy: check for library-specific import first (search file content for import patterns),
      then apply call_expression queries gated on the import presence

    gRPC clients (LPLU-12):
    - Import detection: if file content contains "_grpc" or "_pb2_grpc" → High confidence signal
    - new ServiceClient(channel) where ServiceClient ends with "Client" after a grpc import
    - Query: (new_expression constructor: (identifier) @ctor arguments: (arguments (_) @channel))
      Filter: @ctor ends with "Client" and file has grpc import
    - ConnectionInfo: protocol="grpc", target_name=@ctor without "Client" suffix, confidence=High

    evidence: trimmed source line containing the call, max 200 chars
    source_file: "relative_path:line"

    Tests (inline fixtures, no filesystem):
    - fetch("/api/users") → ConnectionInfo protocol=rest, evidence contains "fetch"
    - axios.get("http://orders-svc/orders") → target_name contains "orders-svc"
    - producer.send({ topic: "payments" }) → protocol=kafka, path="payments"
    - mongoose.connect("mongodb://...") → protocol=mongodb
