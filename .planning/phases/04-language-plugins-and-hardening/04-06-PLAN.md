    Framework marker check (LPLU-08):
    - Scan ctx.files for files ending ".csproj"
    - content.contains("Microsoft.AspNetCore") OR content.contains("Sdk=\"Microsoft.NET.Sdk.Web\"")
    - If no marker: skip route detection

    Two-phase ASP.NET Core extraction (DETQ-05):

    Phase A — class-level [Route] prefix:
    Query:
    ```scheme
    (class_declaration
      (attribute_list
        (attribute
          name: (identifier) @attr_name
          (attribute_argument_clause
            (attribute_argument (string_literal) @route_prefix))?))
      name: (identifier) @class_name)
    ```
    Filter: @attr_name in ["Route","ApiController"]
    Collect class_name → route_prefix mapping

    [controller] token expansion (unique to ASP.NET Core):
    - If route_prefix contains "[controller]":
      expand = class_name.strip_suffix("Controller").unwrap_or(&class_name).to_lowercase()
      route_prefix = route_prefix.replace("[controller]", &expand)
    - Example: class UsersController + Route("api/[controller]") → prefix = "api/users"

    Phase B — method-level [HttpGet], [HttpPost], etc.:
    Query:
    ```scheme
    (method_declaration
      (attribute_list
        (attribute
          name: (identifier) @http_attr
          (attribute_argument_clause
            (attribute_argument (string_literal) @method_path))?))
      name: (identifier) @action_name)
    ```
    Filter: @http_attr in ["HttpGet","HttpPost","HttpPut","HttpDelete","HttpPatch"]
    Infer method: HttpGet→GET, HttpPost→POST, etc.

    Join: walk method_declaration parent chain to class_declaration, expand [controller] in prefix,
    prepend prefix to method_path. Full path = prefix + (method_path or "").

    Tests:
    - `[ApiController][Route("api/[controller]")] public class UsersController { [HttpGet("{id}")] public Task Get(int id) {} }`
      → EndpointInfo GET /api/users/{id}
    - `[ApiController] public class ProductsController { [HttpGet("/products")] public Task List() {} }`
      → EndpointInfo GET /products (no class Route → no prefix)
    - No .csproj with AspNetCore → no routes
  </behavior>
  <action>
    Implement csharp.rs.

    [controller] expansion logic:
    ```rust
    fn expand_controller_token(route: &str, class_name: &str) -> String {
        if route.contains("[controller]") {
            let controller_segment = class_name
                .strip_suffix("Controller")
                .unwrap_or(class_name)
                .to_lowercase();
            route.replace("[controller]", &controller_segment)
        } else {
            route.to_string()
        }
    }
    ```

    C# grammar note: method calls are `invocation_expression` (not `call_expression`).
    String literals are `string_literal`. Attribute names are in `attribute` nodes under `attribute_list`.
