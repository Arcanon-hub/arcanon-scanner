3. `pub fn infer_protocols_from_deps(dep_names: &[String]) -> Vec<String>`:
   - Collects all protocols from all deps. Deduplicates. Returns sorted Vec<String>.

4. `pub fn parse_cargo_lock(&self) -> HashMap<String, Vec<String>>`:
   - Path: `self.root/Cargo.lock`
   - Parse TOML. The file is an array: `[[package]]` entries, each with `name: String`, `version: String`, optional `dependencies: Vec<String>`.
   - Use `toml::Value` (already in Cargo.toml). Parse with `toml::from_str::<toml::Value>`.
   - Return map: package_name → dep names (strip version qualifiers from dep strings — split on ' ' and take first token).
   - Return empty HashMap on any error (file absent, parse error).

5. `pub fn parse_go_mod(&self) -> Vec<String>`:
   - Path: `self.root/go.mod`
   - Read file as text. Find all `require` blocks (single-line and block forms).
   - Single-line: `require MODULE VERSION` → extract MODULE.
   - Block: `require (\n    MODULE VERSION\n    ...\n)` → extract each MODULE per line.
   - Skip lines starting with `//`.
   - Return list of module paths.

6. `pub fn parse_gemfile_lock(&self) -> HashMap<String, Vec<String>>`:
   - Path: `self.root/Gemfile.lock`
   - Read file as text. Find the GEM block (starts after `GEM` and `  specs:` lines).
   - Parse gem entries: 4-space-indented lines like `    gemname (1.2.3)` are top-level gems.
   - Their 6-space-indented lines `      depname (>= 1.0)` are direct deps.
   - Build map: gemname → [depname, ...]. Return empty HashMap on error.

7. `pub fn parse_pom_xml(&self) -> Vec<String>`:
   - Path: `self.root/pom.xml`
   - Read as text. Use simple text extraction (no XML library — we don't have one).
   - Find all `<dependency>` blocks. Within each, extract `<groupId>` and `<artifactId>` text. Skip blocks containing `<scope>test</scope>` or `<scope>provided</scope>`.
   - Return list of `"groupId:artifactId"` strings.

**Error handling:** All parse functions return empty collections on failure (missing file, parse error). Log at `tracing::debug!` level.

    - resolve_for_language(registry, language, dep_names, service_roots) → Vec<ResolvedLibrary>
    - For each dep_name in dep_names (from manifest, production only):
      1. If is_blocklisted(dep_name): skip
      2. If cache.contains_key(dep_name): use cached protocols
      3. Else: find_library_source(language, dep_name) → Option<PathBuf>
         - For Python: `env_path/dep_name/` (with underscore/hyphen normalization: replace - with _)
         - For Node: `node_modules/{dep_name}/` (exact name)
         - For Ruby: `ruby_env/{dep_name}-{version}/` — glob for dep_name prefix
         - For Go/Rust/Java/C#: no source scan — use lock file approach instead
      4. If source found: walk_repo(source_dir, &[]) to get files. Build FileContext for each. Call registry.apply_all(files, language, &HashMap::new()). Extract protocol strings from result.connections (deduplicated).
      5. If no source found AND language is Go/Rust/Ruby/Java/C#: try lock file dep approach. Call appropriate parse_*() method. Look up dep_name in the map. Call infer_protocols_from_deps on its direct deps.
      6. Store protocols in cache (empty Vec if not a connection lib).
      7. If protocols non-empty: emit ResolvedLibrary { lib_name, protocols, source_file_hint }.
    - Return Vec<ResolvedLibrary> — only libs where protocols is non-empty.

    - D-07: If language env not found (Python venv, node_modules) at start of resolve_for_language:
      - Log at tracing::info! level: "Python/Node/Ruby environment not found at {root} — library resolution disabled for {language}. Install dependencies for full scan."
      - Return empty vec immediately. NO crash.

    - D-10: Cache format: HashMap<String, Vec<String>> — key is dep_name, value is protocol list. Empty vec = confirmed not a connection lib.
  </behavior>
