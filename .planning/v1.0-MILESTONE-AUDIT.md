## Architecture

```
CLI (main.rs)
  → Load .arcanon.toml config
  → PatternRegistry::load() from CDN (async, ETag cached)
  → Apply user overrides + disabled filter
  → scanner::run()
    → walk_repo() (file discovery with built-in excludes)
    → build_variable_store() (.env, compose, k8s)
    → detect_git_context() (gix + CI fallbacks)
    → Run 15 compiled plugins in parallel (rayon + catch_unwind)
      → 8 config plugins: services, endpoints, schemas
      → 7 language plugins: route extraction only (AST)
    → Per language:
      → Apply CDN patterns (connection detection)
      → Library resolution (scan installed packages for custom SDK connections)
    → Infer service from repo if connections found but no services
    → merge() all results (dedup by root_path)
    → resolve() intra-repo connections (path normalization)
    → assemble() ScanPayloadV1 with pattern metadata
  → Upload to hub OR --dry-run/--output
```
